The change is mostly contained to ReviewsPanel.tsx, alongside a new 349-line concurrent test that drives two reviews through archive, restart, and reconcile at the same time. Three supporting files touch the report deck so the artifacts overlay keeps its own switcher state when the panel refetches.

Worth a human eye: per-row state now lives inside the row component, so anything that re-keys the list on refetch will drop it mid-flight. The rest reads as a clean, well-tested fix.
